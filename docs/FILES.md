# Files Documentation

This document provides a one-line summary for each tracked file in the repository.

## HTML Files

- **addInJs.html** - Simple addition of two hardcoded numbers (10 + 20) displayed on page load
- **addInJsdifferentWay.html** - Interactive addition calculator with two text inputs and validation
- **additionBetweenString.html** - Demonstrates string-to-number conversion using parseInt() for addition
- **additionBetweenStringAnotherMethod.html** - Demonstrates string-to-number conversion using Number() for addition
- **ascendingAnddescendingdata.html** - Sorts an array of student objects by marks in ascending or descending order
- **AvgUsingReduceMethod.html** - Calculates sum and average of numbers in an array using the reduce method
- **binary2decimal.html** - Converts binary numbers to decimal using parseInt with base 2
- **BinaryNumber.html** - Converts decimal numbers to binary using toString(2)
- **DateFormat.html** - Displays current date in DD/MM/YYYY format
- **DatePostfix.html** - Adds ordinal suffix (st, nd, rd, th) to the current day of the month
- **decimalToHexaDecimal.html** - Converts decimal numbers to hexadecimal using toString(16)
- **decimalToOctal.html** - Converts decimal numbers to octal using toString(8)
- **DynamicClock.html** - Real-time clock that updates every second using setInterval
- **evenOddJs.html** - Checks if a user-entered number is even or odd
- **factorialInJs.html** - Calculates factorial of a number using a for loop
- **GreetingByjs.html** - Displays time-based greeting (morning, afternoon, evening, night) based on current hour
- **implementationOfSessionStorage.html** - Demonstrates sessionStorage API with set, get, and remove operations
- **localStorageImplementation.html** - Demonstrates localStorage API with set, get, and remove operations
- **LuckyCount.html** - Random number game that checks if random value falls between 40 and 80
- **MouseoverAndMouseout.html** - Demonstrates mouseover and mouseout event handlers on a button
- **multipleInJs.html** - Interactive multiplication calculator with two text inputs and validation
- **mutipleInput.html** - Appends multiple text inputs to a paragraph, building a space-separated list
- **octal2decimal.html** - Converts octal numbers to decimal using parseInt with base 8
- **onloadfun.html** - Demonstrates onload event by showing an alert when the page loads
- **QueueInJavascript.html** - Implements a queue data structure using array push (enqueue) and shift (dequeue)
- **simpleCalculator.html** - Four-function calculator supporting addition, subtraction, multiplication, and division
- **simpleClock.html** - Displays current time (hours:minutes:seconds) on page load
- **stack.html** - Implements a stack data structure using array push and pop methods
- **TakingInputUsingPrompt.html** - Prompts user for name and displays personalized time-based greeting
- **task.html** - Alternates prepending and appending incrementing numbers to a paragraph on button clicks
- **TwoWayBindingLikeEvent.html** - Demonstrates two-way binding by updating paragraph text on keyup event
